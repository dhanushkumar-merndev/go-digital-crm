## Server gaps (need a database change — not applied)

- **Quotation tiles follow the selected tab.** `app_private.get_sales_consultant_quotation_workspace_page`
  computes `kpis` from `filtered_rows`, which already has the status tab applied,
  so on the Draft tab Sent and Approval pending always read 0. The fix is to count
  the KPIs before the status filter (as the booking RPC does with `searched_rows`)
  and add `expiring_soon` and `revised` so the tiles can match the canonical set.
- **Bookings has no Cancelled count** for the manager extra.
- **Budget and city on the mobile lead card** (drafted earlier, not applied).

## Needs a decision

- **Exchange as a list.** The PRD lists exchange statuses for the consultant's own
  requests. A list of the consultant's bookings with an exchange status, opening the
  current form for one row, would follow the progressive-disclosure rule without
  removing anything. The data is already in `get_sales_exchange_options`.
- **SLA risk on a consultant's list** counts the derived work-state, which is
  measured from the enquiry, not the handoff. It shows 34 on the demo consultant.
  It stays as the canonical tile; a sales-side SLA would need a definition.
