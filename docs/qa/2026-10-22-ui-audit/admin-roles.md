# UI / UX audit — Digital Marketing, Client Admin, System Administrator, Business Owner, Super Admin (2026-10-27)

Captured with the role-navigation e2e in audit mode against `next dev`;
screenshots and timings are in the git-ignored
`playwright-report/ui-audit/2026-10-27-admin` (before) and `2026-10-27-admin-r2`
(after) folders. After the fixes every sidebar page renders for all five roles.
No page in these roles needed a database change: the slowest calls are the
Edge-cached dashboards (1.3–1.8 s cold) and Client Admin branch performance
(833 ms).
